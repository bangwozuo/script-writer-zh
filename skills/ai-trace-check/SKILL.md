# AI 痕迹自检

发布前把稿子里的「AI 腔」量化挑出来：哪里像机器写的、为什么像、怎么改。
数值由脚本统计（句长/CV/密度），模型负责语境判断与改写方向。

不做的事：不重写整篇稿、不做敏感词审查（那是 sensitive-word-precheck）、
不承诺「平台检测必过」。

## 能力描述

五维量化检测，每维都有数字阈值：

1. **衔接词密度**：「首先/其次/总之/值得注意的是」等 30 词扫描，>3 个/千字判 AI 腔
2. **句长起伏（Burstiness）**：变异系数 CV = 句长σ ÷ 平均句长，≥0.5 人味、<0.4 判 AI 腔
3. **均长连句**：连续 3 句长度差 ≤2 字且 >18 字，一票判 AI 腔的统计指纹
4. **排比三连**：连续 ≥3 句前两字相同，标记不判死（口播排比是节奏手段）
5. **抽象汇报词**：「赋能/抓手/闭环/深度」等，>2 个/千字判汇报腔

综合输出 **AI 痕迹分 0-100**（≥55 高 / 30-54 中 / <30 正常）+ 句段级命中明细 +
逐条可落笔的改写方向。

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `text` | string | ✅ | 待检文稿（口播稿/图文稿均可），≥50 字才出统计结论 |

## 输出规格

- `verdict`：整体判定（高 AI 痕迹 / 中度 / 人味正常）
- `metrics`：字数、句数、平均句长、CV、衔接词与抽象词密度等 12 项指标
- `sentences`：句段明细（句长 / 痕迹标记 / 判定）
- 产物：`out/AI痕迹检测报告.xlsx`（五维汇总+句段明细+词表命中 4 sheet）、
  `out/句长分布.png`、`out/ai_trace.json`

## 使用步骤

### 方式一：纯提示词（最快）

1. 打开任意支持自定义提示词的 AI 工具
2. 把 `prompt.txt` 全文粘贴为系统提示词
3. 提供待检文稿
4. 得到检测汇总 + 句段明细 + 修改优先级

方式一由模型按 prompt.txt 的五维方法人工分句估算，适合快速看方向；
精确数值以下方脚本为准。

### 方式二：带脚本（统计精确 + 产出 Excel）

```bash
python <SKILL_DIR>/scripts/ai_trace_check.py --input input.json --outdir out
python <SKILL_DIR>/scripts/ai_trace_check.py --demo
python <SKILL_DIR>/scripts/ai_trace_check.py --text "要检测的文稿……"
```

产物：

| 文件 | 内容 |
|---|---|
| `out/AI痕迹检测报告.xlsx` | 五维汇总 / 句段明细（🔴 标红）/ 衔接词与抽象词命中 |
| `out/句长分布.png` | 逐句长度折线，起伏大=人写、一条平线=AI 腔 |
| `out/ai_trace.json` | 机器可读结果，供 ai-trace-detect-reduce-flow 读取 |

**分工**：脚本做统计（分句、数句长、算 CV、扫词表，不漏不猜）；模型做语境判断
（引用原文、有意排比的甄别）与改写方向。两者结果交叉核对。

## 边界（不做的事）

- ❌ 不编造检测数值——句长/CV/密度是统计量，以脚本实跑为准，模型不口算
- ❌ 稿件 <50 字不硬给结论，先索要完整稿
- ❌ 不把有意的口播排比、引用原文判成 AI 腔（先拦假阳性）
- ❌ 不承诺「平台 AI 检测必过」——本方法是启发式统计，只给「像不像人写的」参考
- ❌ 不给「让文字更有温度」这类空话，每条命中必须带可落笔的改法

## 调用示例

**输入**（`examples/input.json`）：一篇「副业规划」主题的 AI 腔重灾区稿件（198 字）。

**输出**（脚本实跑，AI 痕迹分 80）：🔴 高 AI 痕迹——衔接词密度 55.6 个/千字
（命中「首先/其次/此外/值得注意的是/与此同时/综上所述/总而言之」等 13 处）、
CV 0.38 < 0.4 句长趋平、抽象词密度 5.1/千字（「全面提升」等）、完美三段式齐活。
修改优先级第 1 条：拆掉「首先规划要考虑市场需求/其次规划要考虑个人能力/最后规划要
考虑长期的成长空间」三句等长排比，改为结论前置：「副业能不能成，就看三件事：
市场要、你 会、熬得住。」
