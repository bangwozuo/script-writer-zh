# 钩子文案锻造

给选题锻造黄金 3 秒开口第一句：每次 10 条候选、覆盖 ≥4 种类型、每条可直接开拍。

不做的事：不写正文、不承诺播放量、不做虚假数据与标题党。

## 元信息

| 字段 | 值 |
|------|-----|
| ID | `de_media_02_sk02` |
| 类型 | **`atomic`（原子技能）** |
| 所属员工 | 脚本创作师 |
| 能力族 | 生成创作型 · 开场文案 |
| 复杂度 | `S` |
| 阶段 | `P0` |
| 复用度 | 高：topic-to-script-flow 的第二棒 |
| 资产形态 | 纯提示词（无运行时依赖） |

## 能力描述

1. **五类钩子公式**：悬念（结果说一半）/ 反差（预期撞事实）/ 利益（数字+获得感）/
   提问（人群+共同困惑）/ 热点借势（事件+角度，半衰期 48-72 小时）
2. **三条铁律**：首句 ≤15 字（3 秒 @4.5 字/秒 只念得下 13-14 字）；3 秒内出现
   信息差；钩子必须能被正文兑现（兑现不了的标「高兑现难度」不硬推）
3. **数据基准**：完播率 >30% 合格、>50% 优秀；3 秒留存看平台后台「3s 观众占比」，
   A/B 跑 3-5 小时定稿
4. **A/B 纪律**：同选题 ≥3 个不同类型（换汤不换药不算）；每条候选标字数、
   信息差位置、兑现难度与风险

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `topic` | string | ✅ | 选题（要讲什么） |
| `audience` | string | ⬜ | 目标人群（痛点要对着写） |
| `platform` | string | ⬜ | 抖音/小红书/B站（默认抖音；B站前 15s+封面标题一并考虑） |
| `evidence` | string | ⬜ | 可用的真实素材/数据（防虚构） |

## 输出规格

- `hooks`：10 条候选表（台词/类型/字数/信息差/兑现难度）
- `ab_plan`：A/B 组合与测法定稿标准
- `risks`：逐条风险标注（虚假承诺/数据无出处/热点时效）

## 使用步骤

### 方式一：直接使用（最快）

1. 把 `prompt.txt` 全文粘贴为系统提示词
2. 提供选题 + 人群（有真实素材更好）
3. 得到 10 条候选 + A/B 建议 + 风险标注
4. 挑 3 条不同类型做 A/B，按 3s 占比定稿

### 方式二：在主流平台导入

| 平台 | 导入方式 |
|------|---------|
| **Coze / 扣子** | 新建 Bot → 人设与回复逻辑 → 粘贴 `prompt.txt` |
| **WorkBuddy** | 新建 Skill → 填入 `prompt.txt` 内容 |
| **Dify** | 新建应用 → 提示词编排 → 粘贴 `prompt.txt` |

### 下游衔接

选定的钩子交给 `script-structure-generate` 作为 0-3s 段落正文的开头；
交付前整体过 `sensitive-word-precheck`。

## 边界（不做的事）

- ❌ 不写标题党——正文兑现不了的钩子标高风险，不硬推
- ❌ 不虚构数据效果（「月入十万」无出处 = 虚假宣传口径）
- ❌ 不用「震惊/99% 的人不知道」低质标题腔
- ❌ 不蹭灾难悲剧与争议人物热点，不擦边
- ❌ 首句超 15 字不交付

## 调用示例

**输入**（`examples/input.json`）：选题「普通人怎么做副业」，人群「25-35 岁上班族」。

**输出**（按 prompt 走一遍）：10 条候选覆盖悬念/反差/利益/提问/热点 5 类，
首句字数 8-14 字全部达标；A/B 推荐组合为悬念型（「他下班只干两小时，月多赚
三千八」）vs 提问型（「为什么你的副业干三天就凉？」）vs 反差型（「越努力的副业，
死得越快」）；风险栏标注「月入三千八须为真实案例数据，无出处则改写」。
