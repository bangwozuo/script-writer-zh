# 敏感词预审

发布前把会被平台限流、下架、封禁的表述挑出来，分级给出可直接替换的写法。

不做的事：不改内容观点、不做 AI 痕迹检测（ai-trace-check）、不提供规避审核的写法。

## 能力描述

三类规则逐类扫描，分级 🔴 红线 / 🟡 警告 / 🔵 提示：

1. **法定违禁词**：《广告法》第九条绝对化用语（最/第一/唯一/100%）、虚假承诺
   （看完包会）、收益承诺（稳赚/保本/零风险——金融口径对带货教程同样适用）
2. **平台限流词**：导流（加微信/私信领/扫码）、诱导互动（扣1抽奖）、夸大堆叠
   （神器/天花板）、擦边蹭热点；小红书交易词、抖音口播其他平台名等平台特有口径
3. **内容红线**：未核实数据（无出处的「据说 90%」）、医疗健康断言（须加免责）、
   BGM 版权（非平台曲库 → 警告）、低俗擦边（直接劝阻）

含语境防误伤规则：「第一人称的我」≠ 排名「第一」；引用原话标注「引用」；
拿不准标 🟡 说明原因，不冒充 🔴。

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `text` | string | ✅ | 待检文本（口播稿/标题/字幕/置顶评论一起给） |
| `platform` | string | ✅ | 抖音/小红书/B站/视频号/通用 |
| `category` | string | ⬜ | 医疗健康/金融/教育等，触发对应资质与免责规则 |

## 输出规格

- `summary`：平台/字数/三级计数/整体判定（通过、修改后发布、不建议发布）
- `hits`：风险清单（级别/原文片段/命中规则/依据/建议改法）
- `need_material`：需补充材料清单（数据出处/资质/检测报告）

## 使用步骤

### 方式一：直接使用（最快）

1. 把 `prompt.txt` 全文粘贴为系统提示词
2. 提供待检文本 + 平台（+ 类目）
3. 得到分级风险清单与替换写法
4. 改完后把修改稿再过一遍（复检）

### 方式二：在主流平台导入

| 平台 | 导入方式 |
|------|---------|
| **Coze / 扣子** | 新建 Bot → 人设与回复逻辑 → 粘贴 `prompt.txt` |
| **WorkBuddy** | 新建 Skill → 填入 `prompt.txt` 内容 |
| **Dify** | 新建应用 → 提示词编排 → 粘贴 `prompt.txt` |

## 边界（不做的事）

- ❌ 不编造违规项——无依据的词不报
- ❌ 不提供谐音/拆字/拼音等规避审核写法——属违规协助
- ❌ 不冒充平台审核结果——规则月月更新，以官方最新规范为准
- ❌ 不做观点审查——只审合规
- ❌ 模糊结论不放行——要么过，要么列清单

## 调用示例

**输入**（`examples/input.json`）：抖音口播稿（副业理财向，含「最靠谱」「稳赚」
「加微信」「神器」「据说 90%」等高风险表述）。

**输出**（按 prompt 走一遍）：红线 5 项（稳赚/最靠谱/第一天/加微信领资料/
未核实数据 90%）、警告 2 项（神器/点关注抽奖）、整体判定「不建议发布」；
逐条给出替换写法（「稳赚」→「收益有波动，附本人记账截图」），
并建议健康/收益类话术加免责标注位。
