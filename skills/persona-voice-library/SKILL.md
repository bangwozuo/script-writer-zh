# 人设语气库

从历史稿件统计出「这个人平时怎么说话」，沉淀成**数值化改写约束**，让口语化改写
改出来的是「他的口语」而不是「通用口语」。

不做的事：不凭空发明人设、不代写稿件、不跨账号复用画像。

## 元信息

| 字段 | 值 |
|------|-----|
| ID | `de_media_02_sk04` |
| 类型 | **`atomic`（原子技能）** |

## 能力描述

五维量化画像，全部来自样本统计：

1. **句长习惯**：平均句长、变异系数 CV、短句（≤8 字）占比——改写目标 = 样本均值 ±2 字
2. **语气词密度**：吧/呢/哈/啊/呗 等每百字个数，目标区间 2-4（<2 生硬、>4 油腻）
3. **人称习惯**：每千字频次；第二人称 <10 个/千字 = 在自说自话；复数称呼不得混用
4. **句式习惯**：疑问句/感叹句占比（提问式结尾是评论区互动抓手）
5. **口头禅候选**：跨 ≥2 篇复现、频次 ≥2 的 2-3 字 n-gram，**待创作者确认**后启用
   （每篇 ≤4 次）

交付形态是**改写约束清单**（每个约束都是可对照检查的数字），不是风格描述。

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `creator` | string | ⬜ | 创作者/账号名 |
| `samples` | array | ✅ | 历史稿件，至少 3 篇，每项 `{title, text}`；合计 ≥800 字 |

## 输出规格

- `profile`：画像汇总（样本量/句长/CV/密度/口头禅候选）
- `per_sample`：逐篇统计（异常篇标注）
- `constraints`：改写约束清单（供 colloquial-rewrite 直接调用）
- 产物：`out/语气画像.xlsx`（画像/逐篇/候选/约束 4 sheet）、`out/逐篇句长分布.png`、
  `out/voice_profile.json`

## 使用步骤

### 方式一：纯提示词（最快）

1. 把 `prompt.txt` 全文粘贴为系统提示词
2. 提供 3 篇以上历史稿件
3. 得到画像 + 改写约束 + 待确认清单（口头禅需人工确认）

### 方式二：带脚本（统计精确 + 产出 Excel）

```bash
python <SKILL_DIR>/scripts/voice_profile.py --input input.json --outdir out
python <SKILL_DIR>/scripts/voice_profile.py --demo
```

| 文件 | 内容 |
|---|---|
| `out/语气画像.xlsx` | 画像汇总 / 逐篇统计（语气词 >4 标红）/ 口头禅候选 / 改写约束 |
| `out/逐篇句长分布.png` | 各篇平均句长柱状图 |
| `out/voice_profile.json` | 机器可读画像，供 voiceover-colloquial-flow 读取 |

**分工**：脚本做统计（分句、n-gram 频次、密度计算）；模型做判断（候选是否人设梗、
异常篇是否代笔）与约束措辞。

## 边界（不做的事）

- ❌ 不凭空发明人设——画像只能来自样本，不足 3 篇或 800 字就列清单索要
- ❌ 不把统计候选直接当口头禅（必须「待创作者确认」）
- ❌ 不混用复数称呼（叫「家人们」的号不得建议「宝子们」）
- ❌ 不把代笔稿/转型期作品混入均值而不标注
- ❌ 约束不豁免敏感词审查——发布前仍须过 sensitive-word-precheck

## 调用示例

**输入**（`examples/input.json`）：副业类创作者「阿栋聊副业」3 篇口播稿，合计 812 字。

**输出**（脚本实跑）：平均句长 9.7 字、CV 0.51（长短句交错节奏成型）、人称密度
52 个/千字（「你/咱们/家人们/兄弟们/姐妹们」）、口头禅候选 10 个——「就是说」
频次 5 跨 3 篇（大概率人设梗）、「一晚上」频次 2 跨 2 篇（巧合，待确认）。
改写约束：平均句长 8-12 字、语气词 2-4 个/百字、口头禅每篇 ≤4 次、
每篇至少 1 个提问式结尾。

## 所属工作流

- `voiceover-colloquial-flow`（口播稿口语化改写——S1 画像作为改写约束输入）
- 独立使用：新账号冷启动前先建画像，后续所有稿件对照检查

## 合规声明

- 输出标注「AI 生成内容」；风格相似 ≠ 本人对稿认可，发布前人工确认
- 样本属创作者私有内容，仅用于其本人画像，不跨账号复用
- 风格统计不改变内容属性，改稿后仍须完成敏感词预审与 AI 痕迹自检
