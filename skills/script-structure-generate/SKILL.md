# 脚本结构生成

把选题变成能直接开拍/开录的脚本：时间轴、字数、语速全部配平，交付即可拍。

不做的事：不做账号定位、不做钩子 A/B（上游 hook-copy-craft 传入）、不剪片不投放。

## 元信息

| 字段 | 值 |
|------|-----|
| ID | `de_media_02_sk01` |
| 类型 | **`atomic`（原子技能）** |
| 所属员工 | 脚本创作师 |
| 能力族 | 生成创作型 · 脚本成稿 |
| 复杂度 | `S` |
| 阶段 | `P0` |
| 复用度 | 高：topic-to-script-flow 与 storyboard-shotlist-flow 的主引擎 |
| 资产形态 | 纯提示词（无运行时依赖） |

## 能力描述

1. **四段式时间轴**（60s 基准，其他时长等比 ±2s）：钩子 0-3s（≤15 字）→
   痛点/背景 3-15s（50-60 字）→ 干货/剧情主体 15-50s（140-180 字）→
   CTA 50-60s（40-50 字）
2. **知识类黄金结构**：主体段内部「结论前置-论据-案例-金句」——先给答案，
   不写「首先我们要了解」
3. **语速配平数学**：中文口播 4-5 字/秒；30s=130-150 字、45s=200-225、60s=240-300、
   90s=360-450、1500 字≈5-6 分钟；单段超预算 ±10% 必须增删；>6 字/秒念不完、
   <3.5 字/秒掉完播
4. **七字段分镜**：镜头号/景别/时长/画面/台词/字幕/音效；台词字数 = 时长 × 语速，
   超字数必超时（3s 镜头最多 13-14 字）
5. **平台重剪规则**：抖音 ≤60s（超出需中视频计划）、B站 3-10 分钟、小红书 ≤4 分钟、
   视频号 ≤60s——同内容多平台要重剪不是搬运（60s→B站扩案例，60s→30s 砍痛点留单论据）

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `topic` | string | ✅ | 选题与要点素材（真实数据/案例，没有就标待补） |
| `duration_s` | number | ✅ | 目标成片时长（30/45/60/90 常用） |
| `platform` | string | ⬜ | 抖音/小红书/B站/视频号，默认抖音 |
| `hook` | string | ⬜ | 上游钩子文案（缺省则本技能按 ≤15 字自拟） |
| `mode` | string | ⬜ | `script`（纯口播稿，默认）/ `storyboard`（带分镜表） |

## 输出规格

- `script`：分段脚本正文（每段标字数与时间轴）
- `storyboard`：分镜表（mode=storyboard 时）
- `balance`：字数配平核对表（段落/时长/字数/语速/判定）

## 使用步骤

### 方式一：直接使用（最快）

1. 把 `prompt.txt` 全文粘贴为系统提示词
2. 提供选题 + 目标时长 +（可选）上游钩子与平台
3. 得到分段脚本 + 配平核对（+ 分镜表）
4. 逐段念一遍，卡壳处退回修改

### 方式二：在主流平台导入

| 平台 | 导入方式 |
|------|---------|
| **Coze / 扣子** | 新建 Bot → 人设与回复逻辑 → 粘贴 `prompt.txt` |
| **WorkBuddy** | 新建 Skill → 填入 `prompt.txt` 内容 |
| **Dify** | 新建应用 → 提示词编排 → 粘贴 `prompt.txt` |

### 校验配套

配平核对表的字数/语速可用 `storyboard-shotlist-flow` 的脚本实测（台词字数、
时间轴连续性同一口径），交叉核对后再交付。

## 边界（不做的事）

- ❌ 不编造数据与案例——没有真实出处标「案例待补」
- ❌ 钩子段超 3s/15 字不放行（上游钩子超标退回 hook-copy-craft）
- ❌ 不交付不配平的脚本——全文与分段字数没数过 = 没写完
- ❌ 医疗健康内容主体段必须留免责话术位，不引用未核实数据
- ❌ BGM 只写风格要求，不指定可能侵权的具体曲目

## 调用示例

**输入**（`examples/input.json`）：选题「副业避坑」（3 个真实坑 + 本人数据）、
60 秒、抖音、上游钩子「副业第一个月，我踩了三个坑」。

**输出**（按 prompt 走一遍）：全文 271 字（语速 4.5 字/秒），四段 13/54/149/45 字
逐段达标；主体段按「结论前置-论据-案例-金句」组织，CTA 提问式结尾收互动；
配平核对表 4 行全部 ✅；分镜表 8 镜头，单镜台词最长 14 字无超时。

## 所属工作流

- `topic-to-script-flow`（选题转脚本——S1 结构成稿）
- `storyboard-shotlist-flow`（分镜与拍摄清单——上游输入）

## 合规声明

- 输出标注「AI 生成内容」，成片按平台规则完成 AI 标识
- CTA 不做虚假承诺；医疗健康类带免责话术位
- 对外发布保留人工确认环节；脚本只到「可拍摄」为止
